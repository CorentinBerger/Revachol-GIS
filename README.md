## Author

The GIS files were created by **Corentin Berger, PhD**. 
The methodology used to reconstruct and map Revachol, the fictional city where the video game Disco Elysium takes place, is presented in a Medium article.

## Repository Structure

The repository contains a QGIS project, **`disco_elysium_revachol_GIS.qgz`**, including a set of example map layouts. The project loads the raster and vector data stored in the repository.

The project uses the **`RussoOne-Regular`** font included in the `fonts` folder, as well as the icons provided in the `icons` folder.

### `rasters`

The `rasters` folder contains the following raster datasets:

* **`revachol_DEM.tif`** — Digital Elevation Model (DEM) of Revachol.
* **`revachol_hillshade.tif`** — Hillshade derived from the Revachol DEM.
* **`revachol_mapmax.tif`** — Georeferenced and digitized map of Revachol by Mapmax.
* **`revachol_west-jamrock_zaum.tif`** — Georeferenced and digitized map of Revachol West and Jamrock originally published by ZA/UM.

### `vectors`

The `vectors` folder contains the following vector datasets:

* **`revachol_contour.gpkg`** — Elevation contour lines of Revachol.
* **`revachol_districts.gpkg`** — Districts and sub-districts of Revachol.
* **`revachol_land_use.gpkg`** — Land-use data for Revachol.
* **`revachol_poi.gpkg`** — Points of Interest (POIs) across Revachol.
* **`revachol_transport-infrastructure.gpkg`** — Transportation routes and infrastructure.
